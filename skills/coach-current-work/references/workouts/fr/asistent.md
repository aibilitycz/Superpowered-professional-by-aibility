# Créez un projet dans l'IA : documents et consignes pour chaque chat

L'IA compile à partir de vos chats un thème unique avec consignes et liste de documents, que chaque nouveau chat du projet connaît.

## Créez un projet dans l'IA : documents et consignes pour chaque chat

**Difficulté : facile.**\
**Durée : environ 15 minutes** avec un thème pour lequel vous avez quelques chats.
## À quoi ça sert

Pendant trois semaines, vous préparez avec l'IA un appel d'offres pour des voitures de fonction et vous ressaisissez les exigences dans chaque chat. Mercredi, vous oubliez de rappeler que la direction a refusé le leasing, et l'IA le recommande à nouveau dans les documents pour la directrice.

Un projet est un espace dans l'outil IA où tous les chats sur un même thème partagent des consignes et des fichiers, ainsi l'IA sait de quoi il s'agit et ce qui est valable avant même que vous écriviez la première phrase.
## Ce qu'il faut préparer

- un thème que vous abordez avec l'IA au moins une fois par semaine, par exemple une newsletter mensuelle,
- le chat où vous avez le plus travaillé sur ce thème,
- les fichiers que vous téléchargez régulièrement sur ce thème : cahiers des charges, tableaux et modèles,
- l'IA que vous utilisez au travail (où il y a des projets, affichant le bloc « Dans votre outil »).
## Comment faire

1. Ajoutez le prompt de l'exercice IA à la fin du chat où vous avez le plus travaillé sur le thème, ou dans un nouveau chat avec le cahier des charges. L'IA écrira le titre, les consignes et la liste des fichiers.
2. Créez un projet avec le nom donné par l'IA, insérez-y les consignes et téléchargez les fichiers de la liste ; la procédure est expliquée dans le bloc « Dans votre outil ». Déplacez-y aussi les anciens chats sur le thème.
3. Dans le projet, ouvrez un nouveau chat et posez une question tranchée, par exemple « Pourquoi avons-nous exclu le leasing ? ». L'IA répondra selon les consignes, sans que vous ayez à insérer quoi que ce soit.
## Exercice IA

Insérez ce [prompt](glossary:prompt) dans l'IA que vous utilisez au travail :

Je souhaite créer un projet pour ce thème afin que chaque nouveau chat sache immédiatement de quoi il s'agit. Prépare-moi tout ce que je dois insérer dans le projet.

Parcours ce chat et les documents que je te fournirai sous cette consigne. Si tu sais chercher dans mes anciens chats, trouve aussi les autres chats sur ce thème et parcours-les également. Commence par indiquer de quels chats et documents tu t'appuies.

Ensuite, écris-moi trois choses :

1. Le nom du projet : court, basé sur le thème, pas sur la tâche du jour.

2. Les consignes du projet à insérer dans ses paramètres. Rédige-les comme une consigne pour l'IA, au maximum sur une page :
- De quoi il s'agit : objectif, pour qui, et échéance.
- Ce qui est valable : décisions prises et ce que nous avons exclu, avec une brève raison.
- Comment travailler : ton, longueur, format et règles que nous avons corrigées à plusieurs reprises dans les chats.
- Documents : quels fichiers du projet sont valables et à quoi ils servent.
- En dernière ligne : « Si une décision est prise ou une règle change dans le chat et concerne tout le projet, écris-moi à la fin de ta réponse la nouvelle version de la ligne concernée de ces consignes. »

3. La liste des fichiers à télécharger dans le projet : fichiers joints ou mentionnés dans les chats, avec une phrase par fichier expliquant son usage. S'il existe plusieurs versions, indique laquelle est valable.

Ne mets pas dans les consignes la tâche du jour ni ce qui ne vaut que cette semaine. Si tu ne peux pas déterminer ce qui est valable dans les chats, ou si deux endroits se contredisent, demande-moi tout en une fois avant d'écrire le résultat. Rédige les consignes en une seule fois pour que je puisse les insérer d'un coup.

## Dans votre outil

### Microsoft Copilot
Le projet est le plus proche du Notebook (Bloc-notes) dans Copilot : sur `copilot.cloud.microsoft` dans le panneau gauche Notes, Nouveau bloc-notes. Téléchargez les fichiers depuis l'ordinateur, OneDrive ou SharePoint, insérez les consignes via les trois points, Instructions et Enregistrer. Déplacez un ancien chat dans la liste Chats via les trois points et Déplacer vers bloc-notes.

### ChatGPT
Dans le panneau gauche, choisissez Nouveau projet. Insérez les consignes via les trois points en haut à droite et Paramètres du projet, téléchargez les fichiers sur la page du projet et glissez-y les anciens chats, ou choisissez Déplacer vers projet. Dans les forfaits Business et Enterprise, le projet accepte 40 fichiers et vous pouvez le partager avec des collègues via Share.

### Claude
Dans le panneau gauche, ouvrez Projets et créez un projet avec le bouton +. Insérez les consignes via Définir les instructions du projet, ajoutez les fichiers avec le bouton + dans les connaissances du projet (project knowledge) et déplacez un ancien chat avec Ajouter au projet.

### Gemini
Le projet est le plus proche du robot Gem dans Gemini : sur `gemini.google.com` ouvrez Robots Gem et Nouveau Gem. Entrez le nom donné par l'IA, insérez les consignes du projet dans les instructions, et si vous avez Gem avec Instructions personnalisées, aussi leur texte. Ajoutez les fichiers dans Connaissances via Ajouter des fichiers et Enregistrer ; vous pourrez modifier les consignes plus tard dans Mes robots Gem.
## Qu'est-ce qu'un projet

Un [projet](glossary:project) a ses propres consignes et fichiers valables uniquement dans ses chats. Les [Instructions personnalisées](card:custom-instructions), c’est-à-dire les consignes propres dans les paramètres du compte, s’appliquent à tous les chats et contiennent ce que l’IA doit toujours savoir, par exemple votre rôle ou la longueur souhaitée des réponses.

Les consignes du projet concernent ce qui vaut pour tout le thème : objectif, règles, décisions prises et quel fichier est valable. La tâche du jour ne fait pas partie des consignes, elle s’écrit dans le chat du projet.
## Pour que les consignes du projet restent à jour

Le thème évolue pendant le travail : la direction prend une nouvelle décision, le fournisseur envoie un nouveau prix. La dernière ligne des consignes du prompt garantit que l’IA vous écrira à la fin de chaque chat la nouvelle version de la ligne concernée. Vous n’avez qu’à la remplacer dans les consignes du projet.

Si votre outil a la mémoire activée, il se souvient aussi de ce qui a été discuté dans les autres chats du projet. Ce qui doit toujours valoir, mettez-le quand même dans les consignes, car l’IA choisit elle-même dans la mémoire et peut omettre quelque chose.
## Exemple

Petra Malá, d’une entreprise vendant du mobilier de bureau, écrit chaque mois une newsletter pour ses clients professionnels. Les nouveautés et promotions changent ; le ton, la longueur et les prix hors TVA restent. À la fin du chat de septembre, elle insère le prompt. L’IA propose le nom « Newsletter pour clients professionnels » et rédige ces consignes :

```text
De quoi il s'agit : newsletter mensuelle pour acheteurs et office managers des entreprises qui achètent notre mobilier. Parution le premier mardi du mois.
Ce qui est valable : prix toujours hors TVA. Les codes promo ne sont plus utilisés depuis août, remplacés par la livraison gratuite au-delà de 20 000 CZK.
Comment travailler : trois blocs de maximum 80 mots, vouvoiement, sans points d’exclamation. À la fin, lien vers le catalogue.
Documents : nabidka-podzim-2026.xlsx est valable, nabidka-leto-2026.xlsx ne l’est plus. newsletter-zari.docx est le modèle de ton.
Si une décision est prise ou une règle change dans le chat et concerne tout le projet, écris-moi à la fin de ta réponse la nouvelle version de la ligne concernée de ces consignes.
```

Petra crée le projet, télécharge l’offre d’automne et la newsletter de septembre, et déplace dans le projet les chats de septembre et août. Le 1er octobre, elle ouvre un nouveau chat dans le projet et écrit simplement « Rédige l’édition d’octobre, les nouveautés sont en pièce jointe ». La newsletter d’octobre contient les prix hors TVA, trois blocs courts et la livraison gratuite au lieu du code promo, même si Petra ne l’a pas mentionné dans le chat.
## En cas de blocage

- **Vous ne voyez pas les projets dans l’outil :** dans Microsoft Copilot, le projet est le plus proche du Notebook et dans Gemini du Gem, la procédure est dans le bloc « Dans votre outil ». Dans un compte professionnel, l’administrateur peut désactiver les projets, demandez-lui.
- **L’IA ne connaît pas les consignes dans un nouveau chat :** vérifiez que le chat est dans le panneau gauche sous le nom du projet et que vous avez bien enregistré les consignes. Si l’IA répond mal malgré tout, demandez-lui quelle ligne des consignes manque et ajoutez-la.
- **Les fichiers ne rentrent pas dans le projet :** les forfaits gratuits acceptent peu de fichiers. Demandez à l’IA de faire un résumé des anciens fichiers, ou passez à une IA qui [travaille directement avec un dossier sur votre ordinateur](card:when-chat-is-not-enough).
- **L’IA mélange un autre thème dans le projet :** dans ChatGPT, passez dans Paramètres du projet à Mémoire limitée au projet. Les chats du projet n’accèdent alors ni à la mémoire ni aux chats hors projet.
## Ce qui sera prêt

Vous avez un projet avec consignes et fichiers sur un thème. Dans un nouveau chat, vous avez vérifié que l’IA connaît les consignes et les décisions. La dernière ligne des consignes garantit que l’IA vous écrira à chaque changement la nouvelle version de la ligne concernée.
## Et ensuite

Quand vous travaillez avec l’IA en mode Cowork ou Code, c’est-à-dire directement avec un dossier sur votre ordinateur, le même travail est fait par la [page d’introduction du projet (README)](card:project-start-here), que l’IA sauvegarde et modifie elle-même. Si vous répétez toujours la même procédure dans le projet, par exemple la vérification des prix avant envoi, transformez-le en [skill](card:create-skill-from-proven-process) : un guide enregistré selon lequel l’IA répète la procédure à chaque fois.
## Projet / espace de travail

**Qu'est-ce que c'est :** Un espace de travail dans lequel l'IA peut utiliser à long terme des conversations, instructions et documents liés à un même sujet ou projet. Les fonctionnalités exactes dépendent de l'outil.

**Ce que ce n'est pas :** Ce n'est pas automatiquement un agent ni un simple dossier de fichiers.

**Pourquoi l'étudiant en a besoin :** Cela aide à reconnaître quand une tâche nécessite un contexte permanent et des documents communs au lieu de tout réinsérer dans une nouvelle conversation à chaque fois.

## Invite

**Qu'est-ce que c'est :** Une instruction pour une interaction spécifique avec l'IA.

**Ce que ce n'est pas :** Ce n'est pas la même chose qu'un contexte à long terme, un assistant ou un agent stocké.

**Pourquoi l'étudiant en a besoin :** Elle déclenche l'exercice et guide son déroulement ; ce n'est pas le contenu principal d'apprentissage.

## Panne de service, limite ou chat saturé

Fallback commun pour les interruptions opérationnelles lors du travail avec l'IA. Accessible depuis chaque carte via l'entrée **Panne ou limite atteinte**. Ne crée pas de carte propre, de check-in ni plusieurs copies du même texte.

La section spécifique **Quand quelque chose ne fonctionne pas** dans la carte traite les erreurs d'entrée, de données, d’outil ou de procédure. Ce mécanisme se déclenche lorsque l’IA ne peut techniquement pas poursuivre le passage.

## Distinguez d’abord ce qui s’est passé

| Ce que vous voyez | Situation probable | Première étape |
|---|---|---|
| L’outil signale une limite atteinte, trop de requêtes ou un délai de réinitialisation | limite tarifaire ou opérationnelle temporaire | notez l’heure de réinitialisation et sauvegardez un point de reprise |
| L’IA oublie le début, refuse une pièce jointe supplémentaire ou signale une entrée trop longue | contexte, fichier ou tâche trop volumineux | créez un transfert et poursuivez dans un nouveau contexte ou environnement plus adapté |
| L’outil ne répond pas, renvoie une erreur serveur ou plusieurs modèles échouent | panne de service | vérifiez le statut officiel et choisissez un remplacement approuvé ou une pause |

Si l’IA répond encore, elle peut nommer la situation et préparer un point de reprise. Sinon, passez cette étape. Répéter la même requête ne sauvera pas l’état du travail.

## Sauvegardez un point de reprise

Avant d’attendre ou de changer d’environnement, conservez le plus petit ensemble permettant de poursuivre en toute sécurité :

```text
Objectif : ...
Ce qui est fait et où : ...
Décisions confirmées et contraintes : ...
Sources ou fichiers utilisés : ...
Prochaine étape la plus proche : ...
Ce qui ne doit pas être modifié ou recréé : ...
```

Si l’IA répond toujours, utilisez :

> Prépare-moi un point de reprise succinct pour continuer dans un nouveau chat ou outil. Conserve l’objectif, les parties terminées, les décisions confirmées, les sources, les contraintes et une prochaine étape. Ne crée rien qui ne figure pas dans la conversation.

Pour un travail plus long, enregistrez le point de reprise dans le README du projet ou un autre espace de travail approuvé. Les entrées sensibles restent uniquement dans un stockage approuvé.

## Limite tarifaire ou opérationnelle atteinte

1. Identifiez quand la limite sera réinitialisée et si elle concerne un modèle, une fonction ou tout le compte.
2. Choisissez entre pause, réduction de l’étendue et modèle ou environnement de remplacement approuvé.
3. Lors du passage, transférez le point de reprise et uniquement les données nécessaires à l’étape suivante.
4. Vérifiez que le remplacement supporte les fichiers, outils et actions requis. Un modèle plus faible peut suffire pour la mise en forme mais échouer en analyse ou travail avec outils.

## Contexte, fichier ou tâche trop volumineux

1. Faites créer un transfert par l’IA avant qu’elle ne perde les décisions antérieures, si elle répond encore.
2. Lancez un nouveau chat ou projet avec le point de reprise et les liens vers les fichiers canoniques.
3. Divisez le travail en unités cohérentes et conservez des critères communs de résultat. Une découpe aléatoire peut perdre les relations entre parties.
4. Si la tâche nécessite plusieurs fichiers, un travail en masse ou des modifications de projet, poursuivez via la carte `when-chat-is-not-enough`.

## Panne d’outil ou de modèle

1. Vérifiez le statut officiel du fournisseur. Traitez les erreurs de compte uniquement si le service fonctionne globalement.
2. Sauvegardez un point de reprise hors de la conversation actuellement défaillante, si elle est encore accessible.
3. Utilisez un outil de remplacement approuvé uniquement s’il possède les capacités nécessaires et que les mêmes données peuvent y être introduites.
4. Si aucun remplacement adapté n’existe, suspendez le travail et notez précisément la prochaine étape. Reprenez après restauration à partir du dernier résultat confirmé.

## Limites de sécurité

- Une limite ou panne ne justifie pas d’introduire des données professionnelles, clients ou personnelles dans un outil personnel non approuvé.
- Un nouveau compte, un forfait gratuit ou un autre fournisseur peut avoir des conditions différentes concernant les données, leur conservation et leur entraînement.
- Le passage entre modèles peut modifier le format, la précision et les outils disponibles. Comparez la première sortie après reprise avec le dernier point confirmé.
- Ne renvoyez pas une action qui a pu s’exécuter avant l’erreur sans vérifier son état. Cela concerne notamment l’écriture dans un système, l’envoi d’un message, un achat ou une suppression.

## Retour à la carte

Après restauration du service ou passage dans un environnement adapté :

1. chargez le point de reprise,
2. montrez à l’IA le dernier résultat confirmé,
3. demandez uniquement la prochaine étape la plus proche,
4. terminez la carte d’origine sans répéter le travail déjà fait,
5. si l’outil ou modèle a changé, notez la différence pouvant avoir influencé le résultat.

## Traçabilité

Le mécanisme ne crée pas de réalisation autonome. Il peut uniquement ajouter au résultat de la carte principale un point de reprise, le chemin choisi et une éventuelle différence après changement d’outil.

## Sauvegarder pour la prochaine fois

Mécanique produit optionnelle après la création d'un résultat utilisable. Ce n’est pas une carte autonome, elle n’a pas de finalisation propre et n’augmente pas le nombre de méthodes complétées.

## Quand elle est proposée
- la personne a marqué le résultat comme utilisable,
- une instruction corrigée, un style, un arbre de décision, un transfert ou un autre élément répétable a été créé pendant le travail,
- le même type de travail est susceptible de revenir.

La mécanique ne s’affiche pas pour un résultat ponctuel sans partie transférable ou lorsque la sauvegarde sécurisée n’est pas claire.

## Ce que la personne voit
Un choix court **Sauvegarder pour la prochaine fois** à côté du check-in commun. Après ouverture, l’IA propose automatiquement :

- ce qui du résultat est réutilisable,
- ce qui changera à chaque fois,
- ce que la personne doit vérifier lors de la prochaine utilisation.

La personne confirme ou corrige la proposition. La mécanique ne crée pas de formulaire obligatoire supplémentaire.

## Ce que crée l’IA
Le plus petit résultat réutilisable correspondant au travail réel :

- une préférence personnelle courte,
- une instruction ou un prompt,
- une note en Markdown ou dans un second cerveau,
- une mise à jour de projet ou d’assistant,
- une base pour une compétence,
- une modification d’un workflow existant.

Si un artefact approprié existe déjà, l’IA met à jour sa version actuelle au lieu de créer une copie supplémentaire.

## Où le contenu appartient
| Type de contenu | Emplacement par défaut |
|---|---|
| Petite préférence personnelle sans étapes de processus | mémoire ou profil, si cette fonction est disponible et adaptée |
| Instruction canonique, exemple ou description de procédure | Markdown, document ou second cerveau personnel |
| Contexte limité à un seul projet | instructions et fichiers du projet |
| Rôle répétée avec contexte stable | assistant |
| Procédure stable avec règles, exemples et modèles | compétence |
| Plusieurs étapes consécutives | workflow ; pour le choix des étapes et actions, éventuellement branche agentielle |

La mémoire n’est pas un stockage canonique de procédure versionnée. Elle peut conserver une préférence ou un lien vers la source actuelle.

## Quand la forme cible n’est pas claire
La mécanique crée un transfert succinct vers la carte [Créez un projet dans votre outil IA](card:asistent). Elle ne choisit pas de forme sans intervention humaine et ne remplace pas une carte compétence autonome.

## Sécurité et partage
- La mécanique utilise des stockages approuvés connus et les règles d’entreprise.
- Les données du cas spécifique sont séparées de la partie stable.
- Sans autorisation, rien n’est écrit dans le système partagé ni aucun accès modifié.
- Le partage en équipe commence après réutilisation répétée, désignation d’un propriétaire et validation par une autre personne.

## Traçabilité
Une information peut être ajoutée au check-in indiquant qu’un artefact réutilisable a été créé ou modifié. Ce n’est pas une complétion de carte indépendante.
