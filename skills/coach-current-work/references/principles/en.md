## AI First (ai_first)
Try AI on the real task before you start working the old way.

Give AI the goal and the material you already have, then let it make the first attempt. Real work quickly shows what it can handle, where it suggests a better route, and when doing it yourself is faster.

Work examples:
- Turn role notes into a first job-ad draft.
- Give AI the meeting material and ask for discussion points.
- Start a customer reply with an AI draft instead of a blank page.

Private-life examples:
- Turn a garden description into a care calendar.
- Ask AI for a first family-trip route.
- Turn ingredients at home into a dinner idea.

## Choose the tool for the work (tool_fits_work)
When one AI chat is not enough, use a tool that can work with what the task actually requires.

Chat suits questions, text, and a few files; large datasets, folders, or repeated processes may need another approved tool. One tool's limit is not AI's limit.

Work examples:
- Analyze a large spreadsheet with a tool that can run calculations on the data.
- Move repeated work to a tool with access to the whole project folder.
- Find an approved company tool that supports the required format.

Private-life examples:
- Sort contracts and invoices with a folder-aware tool.
- Edit hundreds of photos with a file tool instead of uploading them one by one.
- Plan a trip with a map-based AI tool that knows real routes.

## Brain vs muscle (brain_vs_muscle)
AI can follow known steps or use your goal and evidence to propose a better route.

For a new or unclear task, first use AI to reason, compare options, and challenge assumptions. Once the direction is clear, use it as muscle for fast execution.

Work examples:
- Have AI design useful survey questions before processing the results.
- Compare approaches to a client proposal, then draft the chosen one.
- Ask AI to challenge a quarterly plan before tasks are assigned.

Private-life examples:
- Compare holidays against family needs, then build the itinerary.
- Clarify buying criteria before comparing products.
- Find missing renovation steps before making the work list.

## Everything is a prompt (everything_is_prompt)
Show AI the real material instead of retelling it at length.

A prompt can be a transcript, screenshot, table, photo, email, or rough voice note. Select only what matters for this task and say what you need to get from it.

Work examples:
- Turn a meeting transcript into minutes and open questions.
- Use a broken-form screenshot as evidence for a fix.
- Turn a whiteboard photo into an action list.

Private-life examples:
- Use an appliance-label photo to find the right manual.
- Combine photos of schedules into one overview.
- Describe a party by voice and get a first programme.

## Context is king (context_is_king)
AI responds better when it knows your situation, goal, and rules that also matter next time.

Good context names the audience, prior decisions, constraints, style, and what good looks like. Save repeated context, keep it current, and do not rely on stale material.

Work examples:
- Use successful older articles to write in the established style.
- Share the latest project decisions so rejected ideas do not return.
- Provide the client, constraints, and a proven proposal example.

Private-life examples:
- Keep regular family preferences available for trip planning.
- Provide the plant types and location for a garden plan.
- Share someone's interests and previous gifts before choosing another.

## Iterate (iterate)
Treat the first result as a start and say specifically what to keep and what to change.

The first version exposes missing instructions. Point to the exact part, add evidence or a good example, and stop when the result serves its purpose and further changes add little.

Work examples:
- Keep an email opening and shorten only the second half.
- Change the information order after seeing the first page draft.
- Keep report charts and rewrite only the executive commentary.

Private-life examples:
- Remove one stop from an overloaded trip and recalculate the route.
- Change only the overly formal tone of an invitation.
- Add real room dimensions and revise the layout.

## Verify (verify)
For important results, compare claims and numbers with the original evidence.

Match the depth of checking to the cost of an error. AI can flag unsupported points, but important figures, contracts, and decisions must return to the original source or calculation.

Work examples:
- Compare report totals with the data export before sending.
- Check contract dates and amounts against source documents.
- Trace a striking article statistic back to the original study.

Private-life examples:
- Confirm dates and cancellation terms with the carrier.
- Check a billing discrepancy against the invoice.
- Compare a seller's claims with the item's documents.

## Work is a system (work_is_system)
Build a larger task from connected steps that AI can help design and execute.

One huge request easily skips a vital part. Let AI propose what to learn, choose, create, and verify, then use each step's result as the next step's input.

Work examples:
- Prepare report data, then changes, then commentary.
- Split a workshop into goals, outline, materials, and feedback.
- Start a website with structure, then content, then the first page.

Private-life examples:
- Split a move into inventory, dates, and daily tasks.
- Plan a family trip in parts so one change does not rewrite everything.
- Build a garden plan from layout, plants, and work schedule.

## OHIO: Handle it once (ohio)
When AI work succeeds, immediately capture something reusable for next time.

Only Handle It Once means preserving the working method before it disappears in chat history. The second similar task is already a signal to create a prompt, template, checklist, or short instruction.

Work examples:
- Turn a successful customer reply into an objection template.
- After a report, record the process and rules for next month.
- Turn podcast corrections into a guide for later episodes.

Private-life examples:
- After a trip, create a reusable packing list.
- Turn a good cooking week into a repeatable plan and shopping list.
- Save document-sorting rules for future files.

## AI can program (ai_can_program)
When a tool is missing, describe the useful outcome and let AI build small software.

You do not need to know how to program it. Show the inputs, describe the useful output, test the first version, and adapt it for reuse only after it proves useful.

Work examples:
- Turn text into an HTML presentation instead of assembling slides manually.
- Build a dashboard from a table with period and department filters.
- Create a tool that renames and sorts project files.

Private-life examples:
- Build a calculator for trip-cost options.
- Turn holiday tips into a simple family travel page.
- Create a tool that sorts photos by chosen rules.
